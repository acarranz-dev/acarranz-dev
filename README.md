### 👋 About me

I build **agentic infrastructure**: small, specialised language models running
locally in containers, orchestrated so that, well connected, they perform like a
large one. My background is low-level: C, C++, Linux processes, sockets and
Docker, learned the hard way at **42 Barcelona**.

🎯 Open to roles in **AI infrastructure and data center operations**.
